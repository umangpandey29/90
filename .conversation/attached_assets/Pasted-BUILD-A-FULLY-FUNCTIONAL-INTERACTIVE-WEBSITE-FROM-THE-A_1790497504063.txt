BUILD A FULLY FUNCTIONAL INTERACTIVE WEBSITE FROM THE ATTACHED PDF

1. PROJECT OVERVIEW

Build a complete, production-quality, responsive web application based on the attached PDF: "CLASS 9: 90-DAY STRATEGIC BLUEPRINT".

The PDF is the single source of truth for the study-plan content.

I do NOT want a simple PDF viewer, PDF-to-HTML conversion, screenshot recreation, or static table.

I want the PDF transformed into a fully interactive 90-day student preparation tracker website.

The website should preserve the study plan, terminology, day-by-day structure, subjects, chapters/topics, targets, milestones, and Base/Mid/Peak performance system from the PDF while adding the functionality required to make it behave like a real digital tracker.

The result should feel like a polished modern productivity/study application.

Think:

Study Planner + Productivity Dashboard + 90-Day Journey Tracker

NOT:

A PDF displayed inside a browser.

---

2. IMPORTANT SOURCE-OF-TRUTH RULE

The attached PDF contains the actual 90-day curriculum and study plan.

Before building the application:

1. Read and analyze the entire PDF.
2. Extract all available:
   - Days
   - Dates
   - Months
   - Subjects
   - Chapters
   - Topics
   - Target/action plans
   - Monthly milestones
   - Performance system
   - Final readiness checklist
3. Store this information as structured application data.
4. Do NOT manually invent different chapter names, dates, targets, or study tasks.
5. Do NOT replace the PDF's study plan with a generic Class 9 curriculum.
6. Preserve the PDF's terminology wherever possible.
7. If something is unclear or not present in the PDF, do not silently invent it.

The PDF should remain the authoritative source for the actual study content.

The website functionality is allowed to expand around the content, but the underlying study-plan content must remain faithful to the PDF.

11. BASE / MID / PEAK SYSTEM

The PDF defines the performance system as:

BASE:
Weak understanding, requires urgent re-revision.

MID:
Moderate clarity, requires problem solving.

PEAK:
Full mastery and exam readiness.

Implement this exactly as the core performance-rating system.

The user must be able to select one of:

BASE
MID
PEAK

Once selected:

- Save the rating
- Display it on the relevant day
- Include it in analytics
- Include it in weak-area calculations

If a day is rated BASE, automatically classify it as a weak area.

If it is MID, classify it as developing.

If it is PEAK, classify it as mastered.

Do not automatically change the user's rating.
